# ペルソナ

## ペルソナ 1: 初回利用ユーザー

- 仮名: 深夜に寝つけない初回利用者
- 状況: 寝ようとしても頭が切り替わらず、刺激の強いコンテンツは避けたい夜にアプリを初めて開く。
- 主な目標: 迷わず短い手順でセッションを始め、画面操作を増やさずに眠気へ移りたい。
- 重視する価値: 開始までの速さ、暗い画面、落ち着いた音声、わかりやすいモード選択。
- 困りごと: 説明や設定項目が多いと覚醒しやすく、強い光や複雑な操作で眠気が遠のきやすい。
- 制約: 疲れていて判断力が落ちており、長文の説明や複数画面の遷移に耐えにくい。
- 関連ストーリー: US-01, US-03, US-04, US-05, US-06

## ペルソナ 2: 継続利用ユーザー

- 仮名: 自分に合う入眠パターンを探している継続利用者
- 状況: 既に数回利用しており、前回眠りやすかったジャンルやモードをなるべくそのまま使いながら、その夜の状態に合わせて必要なときだけ調整したい。
- 主な目標: 毎回判断を増やさず前回設定で素早く再生を始め、連続再生中も必要最小限の調整だけで心地よい状態を保ちたい。
- 重視する価値: 前回設定の自動復元、セッション進行の一貫性、BGM 調整のしやすさ、モード差の体感、将来の自分向け最適化への期待。
- 困りごと: 起動直後にジャンルやモードを毎回選び直させられると覚醒しやすく、コンテンツの流れや音量変化が不自然だと使い続けにくい。
- 制約: 半分眠い状態で使うことが多く、画面を注視したり深い階層を辿る操作には向かない。
- 関連ストーリー: US-01, US-02, US-03, US-04, US-05, US-06, US-07, FUTURE-01

## ペルソナとストーリーの対応方針

- 初回利用ユーザーは「迷わず開始できること」と「低刺激に体験へ入れること」を中心に評価する。
- 継続利用ユーザーは「前回設定で迷わず始められること」「体験の一貫性」「再生中の最小調整」「将来のパーソナライズ準備」を中心に評価する。
- 両ペルソナとも、睡眠導入体験を妨げない暗い画面と穏やかな再生テンポを前提条件として共有する。
